# Model assets

No sample model is bundled. Use **File → Open Model** to load a local glTF 2.0 file (`.gltf` or `.glb`) or another format enabled by the Assimp dependency. The renderer expects right-handed, +Y-up input coordinates and preserves source units. Diffuse/base-color and specular texture maps are reported in the log and are not rendered in this release.
